# Awin Trades website

Live at https://awizzlebased.github.io/awintrades/ (GitHub Pages, built with Jekyll).

- `index.html`: home page. Each other page has its own folder: `journal/`, `learn/`, `how-i-trade/`, `community/`, `about/` (each an `index.html`).
- `_layouts/site.html`: the shared styles, footer and scripts. `_includes/header.html` (menu) and `_includes/meta.html` (titles, link previews, icons).
- `_config.yml`: site settings, including the Discord and YouTube links.
- `assets/og.jpg`: the link preview image. `assets/icon/`: the site icon.
- `_posts/`: one file per journal entry. See POSTING.md.
- `assets/`: images.

Education only, not financial advice.
